# 단면도 익스플로러 (Section View Explorer)

기계 CAD(SolidWorks 등) 입문 전, **기계 부품의 단면도 원리를 손으로 직접 체험하며** 익히는 웹 기반 학습 도구입니다. 3D 부품을 마우스/터치로 자르며 단면이 어떻게 달라지는지 실시간으로 확인할 수 있습니다.

설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인에서도 작동합니다. (PC·태블릿·모바일 지원)

## 기능

- **자유 탐색** — 부품·절단 방향(X·Y·Z)을 골라 단면 변화를 관찰. 단면도 종류(온·반·부분·계단) 토글 제공
- **도전 · 매칭** — 목표 단면과 똑같은 단면을 만들도록 절단면을 맞히기
- **도전 · 탐정** — 단면만 보고 어떤 부품인지 맞히기. 방향을 바꿔가며 추론하고, 오답 모델도 3D로 비교
- **도전 · 단면 종류** — 온단면도 / 반단면도 / 부분단면도 / 계단단면도를 구분해 맞히기

수록 부품 10종(구멍 블록, 축·핀, 부싱, 육각 머리, 계단 블록, L자 브라켓, 속 빈 파이프 등)과 실제 기계제도 규격을 따른 빗금(해칭)·중심선·파단선·계단 절단선 표현을 담았습니다.

## 사용법

| 동작 | 방법 |
|------|------|
| 모델 회전 | 3D 화면 드래그 |
| 절단면 이동 | 주황색 절단면(또는 핸들) 드래그 / 하단 슬라이더 |
| 확대·축소 | 마우스 휠 / 두 손가락 핀치 |
| 절단 방향·부품·모드 변경 | 오른쪽 패널 버튼 |

## 기술 정보

- 단일 HTML 파일, 외부 의존성은 [three.js](https://threejs.org/)(CDN) 뿐
- Chrome · Edge · Firefox 최신 버전 권장
